# Architecture Decision Records

This directory records significant architectural decisions for this project, one file per
decision, using the [MADR](https://adr.github.io/madr/) lightweight format. Records are
immutable once accepted — to change a decision, add a new ADR that supersedes the old one
rather than editing it.

|-----|-------|--------|
| [0001](0001-minimal-orca-plugin-worker.md) | Keep the Orca plugin worker a minimal, review-friendly permissions core | Accepted |
